# 音声出力

## 音声出力について

以下の出力をttsコマンドで音声化すること:
- ユーザーへの応答メッセージ
- 思考プロセス（<thinking>タグ内の内容）
- 確認や質問

以下は音声化しない:
- コマンド実行結果の生ログ
- ファイルの内容表示

音声化する文字列に英語が含まれていた場合、英語部分をカタカナ英語に変換して聞き取りやすいように変換して出力すること。
詳細な変換ルールは `.claude/docs/voice-conversion-rules.md` を参照。

ttsコマンドは以下のように使用します。

```
$ tts ${音声として出力する文字列}
```
